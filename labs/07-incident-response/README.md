# Lab 07 — Incident Response Tabletop

## Objective
Practice investigation and response decisions without changing real infrastructure.

## Scenario
A fictional role performs an unexpected sensitive API action from an unfamiliar source. Use only synthetic events.

## Tasks
1. Establish the timeline and identity chain.
2. List evidence gathered and evidence missing.
3. Assess impact and confidence.
4. Propose containment options, including risks of each.
5. Define escalation and communications.
6. Write lessons learned and prevention actions.

## Deliverable
An incident report, timeline, and follow-up action list.
