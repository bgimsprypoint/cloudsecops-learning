# Lab 03 — IAM Investigations

## Objective
Reason through authorization outcomes from policy documents and synthetic scenarios.

## Tasks
1. Create a fictional scenario with a role, identity policy, resource policy, and optional boundary/SCP.
2. Predict whether each request should be allowed or denied.
3. Include explicit deny, missing allow, and condition mismatch cases.
4. Document how you would verify the outcome using approved AWS evidence.

## Deliverable
A scenario matrix with principal, action, resource, policy facts, expected result, and reasoning.
