# Lab 05 — Prowler

## Objective
Use Prowler and/or another IaC scanner to identify configuration risks before deployment.

## Tasks
1. Review current Prowler documentation and supported scan modes.
2. Run an IaC scan against a small Terraform fixture if supported by the current version.
3. Export results to a local file.
4. Prioritize findings and explain the rationale.
5. Remediate and compare results.

## Safety
Do not provide live AWS credentials or scan an account without explicit authorization.
