# Lab 04 — CloudTrail Analysis

## Objective
Build an investigation from synthetic CloudTrail-like JSON events.

## Tasks
1. Create sanitized synthetic events for normal activity and a suspicious sequence.
2. Build a chronological timeline.
3. Identify actor, action, source, affected resources, and errors.
4. State what cannot be concluded from the available evidence.
5. Write a concise incident summary and recommended next steps.
