# Lab 01 — Local Environment and Threat Model

## Objective
Create a safe, repeatable workstation workflow and define what you are trying to protect.

## Tasks
1. Record OS and tool versions (do not include secrets).
2. Write a short threat model for a hypothetical multi-account AWS environment.
3. Identify assets, trust boundaries, likely threats, preventive controls, detections, and response owners.
4. Document which exercises can be completed locally and which require a real AWS sandbox.

## Deliverable
Save `threat-model.md` and an emulator capability matrix in this folder.
